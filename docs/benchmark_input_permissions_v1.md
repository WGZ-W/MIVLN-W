# MI-VLN 第一版输入权限表

版本：`v1.0-draft.1`；日期：2026-11-12。

当前主采集先使用 [目标替换、子目标插入与恢复](benchmark_active_scope.md)。下表保留区域/G 权限作为后置扩展，不要求为当前两类提供禁区信息。

## 1. 状态与角色

本表细化 [三类任务协议](benchmark_task_protocol_v1.md) 的输入边界，是 B1 文档约定。
已实现 [U/G 数据边界](benchmark_public_inputs.md) 和独立 [V RGB 契约](benchmark_visual_inputs.md)，后者包含逐步请求、历史和实际 PNG 白名单；真实 RGB 收集/导航接线和完整隔离仍待完成。
现有语言更新请求已有字段白名单，不能据此声称完整导航进程已经隔离所有私有数据。

| 标记 | 角色 / 拟议轨道 | 目的与当前状态 |
| --- | --- | --- |
| V | 视觉语言导航 Agent | 已有 RGB 请求/动作契约及合成 CPU 回调；真实场景接线尚未完成 |
| U | 符号任务更新器 | 根据消息、候选及声明的上下文预测更新；已有离线三类更新，在线导航目前只接通目标替换 |
| G | 受控几何辅助导航 Agent | 允许坐标、定位和网格，但更新含义由方法解释；已有最小消息契约与合成示例，尚无统一导航入口 |
| O | 特权 Oracle 策略 | 读取正确更新和几何，验证任务可行性与规则；已有三类实验 |
| E | 环境、投递器与独立评价器 | 管理场景、正确标注、投递及评分，不作为参与方法 |

V/U/G 是不同输入配置，不默认共用排行榜。传感器扩展、额外地图或已知符号上下文必须记录在方法配置中，分别报告结果。
角色表示组件边界：一个方法可以由 U 加受控执行器组成，但不能只报告 U 看不到坐标，就省略执行器的特权。
策略输出可为动作或指定轨道的符号更新，不要求所有方法内部维护 `TaskState`。

## 2. “独立任务真值”具体指什么

假设正确标注是“取消 A，改去 B”，模型却理解成去 C：

- 策略按其实际预测去 C，错误执行要保留。
- 评价器根据预先审核的标注，在实际投递时把目标从 A 更新为 B，最后仍按 B 评分。
- Oracle 可读取正确更新，直接去 B，为可行性提供对照。

这里的真值来自任务标注、事件规则和实测证据，不需要额外调用一个模型判断模型是否正确。
评价器的当前要求随事件及有效完成证据推进；不能随被测方法的误解改变，也不能把正确状态回填给被测方法纠错。
任务标注是否正确另由数据审核保证；“独立”不表示标注永远不会出错。

## 4. 条件权限与上下文来源

### 4.1 观测、标识与几何

- V 默认仅使用 RGB、语言、自己的历史和公开执行反馈。深度、类别语义图、外部候选或地图须另列输入配置，不能混报为同一 RGB 条件。
- 原始 HSSD 标签、runtime object ID 和 source index 不是普通视觉输入。类别/实例扩展必须单独定义可见标签与授权范围；目标隔离诊断掩码始终私有。
- V/G 的自身地图必须来自获准观测及已声明资源；不能从私有场景文件初始化后称为自行构建。
- 候选描述是额外人工语义辅助，不等于方法自行识别了实例。候选目录不能带正确答案标记或按答案筛选/排序；仅两个候选、五个候选等范围必须声明。
- U 的区域候选只包括标识、文本描述和别名，模型预测区域 ID；区域 ID→几何映射留给执行器。
- G/O 可以按自己的当前目标查询几何路线，不能由评价器替换成正确目标的路线，也不接收冻结的 Reference 执行轨迹作为行动提示。
- 当前步号、剩余预算可以公开；未来触发步 k、early/middle/late、条件名、操作标签及含答案的 `event_id` 默认不下发。
  若另设已知任务类型的受控实验，须显式声明该额外信息。
- 新公开请求使用与私有样本关联分离的标识；哈希不能自动消除信息泄漏，不用私有目标、文件路径或答案编码标识。
  旧候选 `target_051` 等仍是符号引用，不代表模型获得了对应位置。

### 4.2 U 的三种输入模式

| mode | 允许的 context | 不可额外加入 |
| --- | --- | --- |
| `latest` | 空对象；当前消息及候选在外层 | 初始指令、历史、旧状态 |
| `history` | `initial_instruction`、已收到的 `message_history` | 正确状态摘要、未来消息 |
| `state` | `previous_state` 的公开符号视图 | 评价器当前状态、区域坐标、参考更新 |

`previous_state` 的约束仅为区域 ID，不包括区域几何。允许状态表示不等于要求普通导航 Agent 使用状态表示。
状态来源必须区分并记录：固定上下文中从公开语言构造、明确给定初始符号上下文、实际模型连续预测所得，三者不能混称。
已有导航回调的初始策略目标由配置给定，后续读取本分支实际策略状态；这是受控已知初始化，不代表模型解析了初始目标或从图像定位。
已有离线单步状态由公开语言规则构建，与连续模型滚动历史也不是同一种上下文来源。
一旦模型预测错误、拒绝或调用失败，下一步不能悄悄换成参考正确状态。

## 5. 已有模型加导航后端的组件边界

| 组件 | 可读信息 | 不能据此进行的操作 |
| --- | --- | --- |
| 语言更新模型 | `message`、公开候选、当前 mode 的 context 及公共契约提示 | 读完整 episode、坐标、网格、参考答案或终点诊断 |
| 策略执行器 | 模型实际预测、策略自己的目标、候选到几何的映射和导航网格 | 因预测错误就改走正确目标，或把新真值补进下一次模型输入 |
| 独立评价器 | 预先标注更新、实际轨迹、STOP/完成及诊断证据 | 用策略声明代替正确要求和实测完成 |

现有 `mivln/task_update.py` 对请求使用严格字段白名单；顶层为
`schema_version`、`request_id`、`mode`、`message`、`candidate_goals`、`candidate_regions`、`context`。
每个候选仅允许 ID、`description`、`aliases`，状态约束投影为区域 ID。
`mivln/navigation_updates.py` 构建不透明导航请求；当前在线回调固定 state 模式、只执行目标替换，未向模型提供 RGB。
因此现有模型导航结果应声明为“语言更新 + 特权导航后端”，属于受控基线证据。

上述白名单校验字段结构，不能自动发现自由文本描述、别名、路径或 ID 中夹带的答案，也不能阻止同进程任意读文件。
仍需文本/标识审核、输入来源检查、导出检查及执行隔离。运行器、诊断和策略当前共用进程，文档边界不等于物理隔离已完成。

## 6. 禁区的两种输入方案（后置参考）

| 方案 | Agent 得到什么 | 发布前验收要求 | 当前状态 |
| --- | --- | --- | --- |
| V：视觉/语义可定位区域 | 当前语言，加实际观测中可确定 R 的标记或语义依据 | 独立审核者仅凭获准输入能定位同一边界，评价器另持几何真值；标记必须进入策略实际观测 | 已有实际 RGB 标记字节检查；真实三维投影、遮挡和语义定位仍待验收 |
| G：几何辅助区域 | 投递后提供明确的区域描述及坐标；解释消息仍由方法完成 | 坐标系、定位、Agent 半径和区域目录权限清楚，所有比较方法权限一致 | 拟议方案，尚无统一公开入口 |

G 已有消息契约，未来若恢复禁区采集，再解决 V 的可观察数据；当前不安排禁区新实验，G 的历史结果单独报告。
G 可公布当前标记的区域目录及对应几何，但不能附送“应执行 add_avoid_region”的正确操作标签；
若输入直接给出正确约束更新，则应归为 O 或另行声明的指令已解析基线。
现有历史禁区只完成 O/E 验证。仅在导出视频画矩形能辅助人工理解，不构成已提供给 Agent 的信息。

## 7. 文件、日志与消息投递边界

| 资产 | 是否能直接作为普通 Agent 输入 |
| --- | --- |
| B0 `manifest.json`、`task_index`、`episode_index` | 不能，含场景来源、分支身份、答案关联及评价证据 |
| 原始 `config.json` / `episode.json` / `experiment.json` | 不能，含目标几何、计划事件及私有标注 |
| 已发生本分支的 RGB/深度帧 | 仅通过该轨道获准的传感器接口逐时提供，不能开放未来帧目录 |
| `trajectory.json` / `events.json` / `replans.json` | 不能整体透传，混有任务真值、规划与未来执行信息 |
| `final_task_state.json`、`metrics.json`、`terminal_diagnostics.json` | 不能在线提供，供评测与事后审计 |
| U 的经核验请求或单次公开请求预览 | 仅在 U 对应输入模式和阶段允许范围内可用，不扩张为导航配置权限 |
| 跨步骤完整 `model_inputs.jsonl` / 模型响应日志 | 属于审计资产；单次过去的自身请求/响应可按轨道使用，整份日志不能预读 |

已实现的 U/G 构造器从字段白名单重新构造独立公共对象；后续轨道也必须如此，不能仅删除几个答案字段后复用私有字典。
公开包不带能直接读取私有目录的路径、符号链接、凭据、模型调用配置或实例几何注册表。
仅有公开 schema 还不够：正式在线运行须使策略无法访问评价器对象、私有文件和未投递队列，并记录实际发送的请求/观测及其哈希。
隔离方案和数据许可仍待实现/审核，本稿不声称已有沙箱执行服务。
