## 2. 各类实测结果

| 类型 | Oracle 成功 | Ignore 任务成功 | Ignore 预期失败验收 | Oracle 平均路程 / m |
| --- | ---: | ---: | ---: | ---: |
| 目标替换 | 10/10 | 0/10 | 10/10 | 12.442 |
| 插入恢复 | 10/10 | 0/10 | 10/10 | 22.600 |
| 取消停止 | 10/10 | 0/10 | 10/10 | 4.408 |

Oracle 三类宏平均成功率为 1.0；它是特权控制器的任务可行性结果，不是视觉模型准确率。
六十个分支碰撞计数合计为 0。Ignore 三类均继续完成原始 A，平均路程为 8.659 m。
Ignore 未满足更新后的义务，不能因其路程较短就解释为比 Oracle 更高效，也不能将其混入方法成功率分母。

### 替换

Oracle 在十个新目标 B 正确 STOP，并满足距离、朝向及指定实例证据。Ignore 虽到 A，更新后的评价目标仍为 B，因而全部失败。
该结果说明目标替换后评价真值与 Ignore 的旧目标策略保持分离。

### 插入与恢复

十个 Oracle 分支均有恰好一次有效的 B `COMPLETE_SUBGOAL`，随后恢复 A 并正确 STOP。
最长 Oracle 路线是 `task_007`，34.312 m、200 个动作；平均为 22.600 m、145.6 个动作。
十个 Ignore 分支均缺少有效 B 完成，即使到达 A 也不能满足 B→A 顺序。

### 取消并停止

十个 Oracle 分支的 STOP 延迟全部为 0，取消后路程全部为 0。
表中的平均 4.408 m 是包含介入前运动的全程路程，不是取消后仍在移动。
Ignore 在取消后仍走 2.258—6.750 m，延迟 14—38 个动作才 STOP；平均多走 4.251 m、平均延迟 24.9 个动作。
它们虽到达 A，仍被正确判为取消失败，说明评价器没有将原目标到达误当作遵从取消。

## 3. 此结果证明了什么

本批验证真实 RGB/动作接线、动作前一次投递、不中断位姿/历史、实测 B 完成与 A 恢复、取消立即 STOP，以及普通 V 输入与私有评价信息的分离。
独立审计从原始响应、V 请求/PNG、实例掩码和原网格动作重放复算，不依赖 metrics/summary 的成功标志。
每个任务的事件前配对和三条 Ignore 全程物理/RGB 配对均通过；外部复用源仍可追溯。

当前仍仅一个场景、十个基础任务、middle 时机。Oracle/Ignore 直接使用私有更新和几何，没有调用真实视觉模型。
审计不重新渲染场景，也不提供相机认证；完整隔离、多场景及正式发布评分仍待完善，`release_ready=false`。
已批准的初始/介入语言仍是模板表达，时机、条件和相关措辞不能当作新的独立基础任务计数。
